    good to know

    A web page can't turn into vector shapes and still stay interactive, so the svg hosts your original page, byte for byte, inside itself. That keeps the layout, the code, the fonts and the behaviour exactly the same as the html file.

    Open the .svg directly in a browser (or host it, for example on GitHub Pages). Where an svg is only shown as a picture, like an <img> tag, a README, or most upload sites, browsers switch scripts off, so it won't be interactive there.
